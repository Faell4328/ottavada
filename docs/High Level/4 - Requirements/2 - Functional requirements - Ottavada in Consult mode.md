# 1. Songs

## 1.1. Available operations

The user must be able to:

- **open**, expands the song and shows all its scores;
- **open local**, opens the file explorer in a temporary folder with that song's scores uncompressed;
- **add/remove from favorites**.

---

# 2. Scores

## 2.1. Available operations

The user must be able to:

- **open**, the score will be opened using the default application associated with the file extension.

---

# 3. Operational transparency

The system must display the progress of all performed steps.

## 3.1. Download from cloud steps (check changes)

Steps:

1. Identify changes;
2. Apply events and/or snapshot;
3. Download new or modified files.

It should only move to steps 2 and 3 if something is identified in step 1.

---

# 4. Settings

The user must be able to:

- change the computer name;
- change the organization name;
- change the Ottavada mode;
- change the cloud provider;
- check for updates;
- change the language;

---

# 5. Startup

During application startup, the system must:

1. Check if there is an update.

2. Send telemetry.

3. Check for changes.
