# Explicação sobre a estrutura

Tudo que tiver no "Alto Nível" deve estar detalhado no "Baixo Nível".

## Alto Nível

É foca em explicar a parte de alto nível do software:

- Regra de negócio

- Requisitos

## Baixo Nível

É focado na parte de implementação do código

- Tecnologias e ferramentas

- Modelagem

- Fluxos
